# ClarVar Snakemake Workflow

This workflow executes `clarvar pipeline` on multiple VCF files in parallel using Snakemake.

## Requirements

* Python
* Snakemake
* ClarVar installed and available on PATH

## Configuration

Edit `config.yaml`:

```yaml
input_dir: "data/sample"
output_dir: "results"
assembly: "GRCh38"
sample_sheet: ""
```

## Input Options

### Directory Mode

Place VCF files in the configured input directory:

```text
data/sample/
├── sample1.vcf
├── sample2.vcf
└── sample3.vcf
```

### Sample Sheet Mode

Provide a CSV file:

```csv
sample,vcf
sample1,data/sample1.vcf
sample2,data/sample2.vcf
```

Then set:

```yaml
sample_sheet: "samples.csv"
```

## Run

```bash
snakemake -s workflow/Snakefile --cores 4
```

## Output

Per-sample outputs are written to:

```text
results/
├── sample1/
├── sample2/
└── sample3/
```

Each sample directory is expected to contain the outputs generated by:

```bash
clarvar pipeline
```

including:

```text
prioritised.vcf
prioritised_variants.tsv
report.json
report.html
```

A cohort-level summary is also generated:

```text
results/cohort_summary.json
```
